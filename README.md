

# **Employee Management Web App**

A small web application developed with Spring Boot that allows you to add and manage employees in a database.

## **Technologies**
- Java 23  
- Spring Boot  
- Spring Web  
- Spring Data JPA  
- H2 / MySQL  
- Maven  

## **Features**
- Add an employee (`POST /employee`)  
- Retrieve an employee by ID (`GET /employee/{id}`)  
- List all employees (`GET /employee`)  
- Delete an employee (`DELETE /employee/{id}`)  

##  Run the Application**
```bash
mvn spring-boot:run
```
